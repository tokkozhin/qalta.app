# ระบบอัตโนมัติ Apple Pay บน iOS 26

หลังจ่ายด้วย Apple Pay แล้ว Qalta บันทึกการซื้อเป็นรายจ่ายได้ จำนวนเงินและร้านค้ามาจากธุรกรรม ส่วนหมวดหมู่และบัญชีจะเลือกทุกครั้งหรือตั้งไว้ล่วงหน้าก็ได้

สิ่งที่ต้องมี: iOS 26 แอป **Qalta** และ **คำสั่งลัด** และบัตรใน Wallet

1.  เปิด **การตั้งค่า → Wallet และ Apple Pay** เปิด **กิจกรรมสด** และ **ข้อมูลเซลลูลาร์**

    ![สิทธิ์ของ Wallet และ Apple Pay](https://qalta.app/assets/apple-pay-ios-26/en/01-wallet-settings.png)
    *สิทธิ์ของ Wallet*

2.  เปิด **คำสั่งลัด** ไปที่แท็บ **ระบบอัตโนมัติ** แล้วแตะ **ระบบอัตโนมัติใหม่**

    ![แท็บระบบอัตโนมัติในคำสั่งลัด](https://qalta.app/assets/apple-pay-ios-26/en/02-automation-tab.png)
    *ระบบอัตโนมัติใหม่*

3.  เลือก **Wallet** — “เมื่อฉันแตะบัตรหรือบัตรผ่านใน Wallet” (จ่ายที่เครื่องชำระเงิน)

    ![ตัวกระตุ้น Wallet ในรายการระบบอัตโนมัติ](https://qalta.app/assets/apple-pay-ios-26/en/03-wallet-trigger.png)
    *ตัวกระตุ้น Wallet*

4.  เลือกบัตรที่ต้องการให้ Qalta ติดตาม แล้วแตะ **ถัดไป**

    ![การเลือกบัตรชำระเงิน](https://qalta.app/assets/apple-pay-ios-26/en/04-select-cards.png)
    *เลือกบัตรที่จะติดตาม*

5.  เลือกหมวดหมู่ของ Wallet ที่ต้องการ (เลือกทั้งหมดก็ได้) เลือก **เรียกใช้ทันที** (ไม่ใช่เรียกใช้หลังจากยืนยัน) แล้วแตะ **ถัดไป**

    ![หมวดหมู่ของ Wallet](https://qalta.app/assets/apple-pay-ios-26/en/05-categories.png)
    *หมวดหมู่*

6.  ในหน้าที่แสดงเป็นไทล์ ให้แตะการ์ดสีเทา **สร้างคำสั่งลัดใหม่** ที่มุมซ้ายบน อย่าเลือกคำสั่งลัดที่มีอยู่จากรายการด้านล่าง

    ![ไทล์สร้างคำสั่งลัดใหม่](https://qalta.app/assets/apple-pay-ios-26/en/06-create-shortcut.png)
    *คำสั่งลัดใหม่*

7.  ตัวแก้ไขว่างจะเปิดขึ้น ในช่องค้นหาการกระทำที่ด้านล่าง พิมพ์ **Qalta** แล้วแตะ **Create Wallet Expense** (ไม่ใช่ “Create Transaction”)

    ![การค้นหา Create Wallet Expense](https://qalta.app/assets/apple-pay-ios-26/en/07-search-qalta.png)
    *การกระทำของ Qalta*

8.  ควรเห็นสองบล็อก: “Receive transaction as input” และการกระทำของ Qalta แตะช่องสีเทา **Amount** (จำนวนเงิน) ในการกระทำของ Qalta — แป้นตัวเลขจะปรากฏ ด้านบนแป้น ให้แตะ **เลือกตัวแปร**

    ![ช่อง Amount และเลือกตัวแปร](https://qalta.app/assets/apple-pay-ios-26/en/08-tap-amount.png)
    *แตะ Amount แล้วเลือกตัวแปร*

9.  ในหน้าเลือกตัวแปร ให้แตะชิปสีน้ำเงิน **อินพุตคำสั่งลัด** ใต้ “Receive transaction as input”

    ![การเลือกอินพุตคำสั่งลัดเป็นตัวแปร](https://qalta.app/assets/apple-pay-ios-26/en/09-select-variable.png)
    *อินพุตคำสั่งลัด*

10.  แตะชิปสีน้ำเงิน **อินพุตคำสั่งลัด** ที่ตอนนี้อยู่ในการกระทำของ Qalta ในแผ่นที่เปิดขึ้น ประเภทควรเป็น **Transaction** อย่าปล่อยเครื่องหมายถูกไว้ที่ “Transaction” — เลื่อนรายการแล้วแตะ **Amount**

     ![คุณสมบัติของ Transaction: แตะ Amount](https://qalta.app/assets/apple-pay-ios-26/en/10-pick-amount.png)
     *ประเภท Transaction → Amount*

11.  ทำซ้ำสำหรับชื่อร้าน แตะลูกศรบนการกระทำของ Qalta เพื่อขยายช่องต่าง ๆ แตะ **Merchant** (ร้านค้า) → **เลือกตัวแปร** → **อินพุตคำสั่งลัด** แตะชิปอีกครั้ง เลือกประเภท **Transaction** แล้วเลือก **Merchant** จากรายการ

     ![การเลือก Merchant จากธุรกรรม](https://qalta.app/assets/apple-pay-ios-26/en/11-merchant.png)
     *ประเภท Transaction → Merchant*

12.  ช่องที่เหลือไม่บังคับ ตัวเลือกสำหรับ **Category** (หมวดหมู่) และ **Account** (บัญชี):

     -   **เลือก** — เลือกหมวดหมู่หรือบัญชีที่ต้องการจาก Qalta หากมีบัญชีเดียว ให้ทำแบบนี้: เลือกครั้งเดียวพอ ไม่ต้องใช้ถามทุกครั้ง
     -   **ถามทุกครั้ง** — หลังการชำระเงินแต่ละครั้ง Qalta จะถามว่าจะบันทึกรายจ่ายไว้ที่ไหน เหมาะถ้ามีหลายหมวดหมู่หรือหลายบัญชี
     -   ปล่อย **เลือก** ว่างไว้ก็ได้ — Qalta จะใช้ค่าเริ่มต้นและพยายามตรวจหาหมวดหมู่ให้

     **Currency**, **Note** และ **Date** (สกุลเงิน โน้ต และวันที่) ปล่อยว่างได้ เปิด **แสดงเมื่อเรียกใช้** เพื่อให้มีหน้ายืนยันหลังการชำระเงิน แล้วแตะเครื่องหมายถูกสีน้ำเงินที่ด้านบน

     ![Category, Account และแสดงเมื่อเรียกใช้](https://qalta.app/assets/apple-pay-ios-26/en/12-category-account.png)
     *หมวดหมู่ บัญชี และการยืนยัน*

13.  ระบบอัตโนมัติจะปรากฏในแท็บ **ระบบอัตโนมัติ** หลังจากซื้อด้วย Apple Pay ครั้งถัดไปด้วยบัตรที่เลือก Qalta จะเสนอให้บันทึกรายจ่าย

     ![ระบบอัตโนมัติที่เสร็จแล้วในรายการ](https://qalta.app/assets/apple-pay-ios-26/en/13-automation-list.png)
     *เรียบร้อย*
