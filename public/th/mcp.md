# MCP

เชื่อมต่อผู้ช่วย AI กับพื้นที่คลาวด์ Qalta ของคุณ

## เชื่อมต่อผู้ช่วย AI

1.  ลงชื่อเข้าใช้ Qalta และตรวจสอบว่าพื้นที่คลาวด์ที่ต้องการใช้งานกำลังซิงค์อยู่ พื้นที่ส่วนตัวที่เก็บไว้เฉพาะในอุปกรณ์จะไม่พร้อมใช้งานสำหรับตัวเชื่อมต่อ
2.  เพิ่มเซิร์ฟเวอร์ MCP https://mcp.qalta.app/mcp ในการตั้งค่าของผู้ช่วย
3.  ลงชื่อเข้าใช้ผ่าน Qalta และตรวจสอบสิทธิ์ก่อนอนุมัติการเข้าถึง
4.  เริ่มจากคำขออ่านข้อมูล เช่น “เดือนนี้ฉันใช้จ่ายกับของชำไปเท่าไร”
