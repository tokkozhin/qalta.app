นโยบายความเป็นส่วนตัว

วันที่มีผลบังคับใช้: 16 ตุลาคม 2026

คำแปลนี้จัดทำขึ้นเพื่อความสะดวก หากมีข้อความแตกต่างจากฉบับภาษาอังกฤษ ให้ถือตามฉบับภาษาอังกฤษ

นโยบายนี้ใช้กับแอปมือถือ Qalta (“แอป”) ซึ่งให้บริการโดย Daniel Tokkozhin (“เรา”) นโยบายนี้อธิบายว่าข้อมูลใดอยู่บนอุปกรณ์ของคุณ ข้อมูลใดออกจากอุปกรณ์ และบริษัทใดประมวลผลข้อมูลนั้น

พื้นที่ส่วนตัวอยู่บนอุปกรณ์ของคุณ

บันทึกของคุณถูกเก็บไว้ในพื้นที่ พื้นที่ส่วนตัว พร้อมบัญชี รายการ หมวดหมู่ งบประมาณ เป้าหมาย หนี้ รายการซ้ำ และข้อมูลอื่นที่คล้ายกันในพื้นที่นั้น ถูกจัดเก็บไว้บนอุปกรณ์ของคุณเท่านั้น (SQLite) เราไม่อัปโหลดพื้นที่ส่วนตัวไปยังเซิร์ฟเวอร์ของเรา

หากคุณใช้ฟีเจอร์สำรองข้อมูลซึ่งเป็นตัวเลือก สำเนาอาจถูกจัดเก็บในบัญชี iCloud ของคุณ พื้นที่จัดเก็บนั้นให้บริการโดย Apple และอยู่ภายใต้นโยบายความเป็นส่วนตัวของ Apple

พื้นที่ที่แชร์

การแชร์เป็นตัวเลือก หากคุณแชร์พื้นที่ พื้นที่นั้นและทุกอย่างในพื้นที่ (ชื่อ บัญชี รายการ การโอน หมวดหมู่ งบประมาณ เป้าหมาย หนี้ รายการซ้ำ และโน้ตที่คุณเพิ่ม) จะถูกอัปโหลดไปยังผู้ให้บริการแบ็กเอนด์ของเรา คือ Supabase และซิงค์กับอุปกรณ์อื่นของคุณและกับคนที่คุณเชิญ เฉพาะสมาชิกของพื้นที่เท่านั้นที่เข้าถึงพื้นที่นั้นได้ แต่ละบันทึกจะแสดงว่าสมาชิกคนใดสร้างและใครแก้ไขล่าสุด

สมาชิกของพื้นที่ที่แชร์สามารถเห็นชื่อ ที่อยู่อีเมล และรูปโปรไฟล์ของกันและกันจากบัญชีที่ใช้ลงชื่อเข้าใช้ รวมถึงเวลาที่สมาชิกแต่ละคนเข้าร่วม คำเชิญเป็นลิงก์ที่ใช้ได้ครั้งเดียวและหมดอายุหลังจาก 7 วัน เราจัดเก็บรหัสคำเชิญในรูปแบบที่ผ่านการแฮชเท่านั้น และคำเชิญที่หมดอายุจะถูกลบโดยอัตโนมัติ

เมื่อเจ้าของหยุดแชร์หรือลบพื้นที่ที่แชร์ ข้อมูลของพื้นที่นั้นจะถูกลบออกจากเซิร์ฟเวอร์ของเรา และสมาชิกทุกคนจะสูญเสียสิทธิ์เข้าถึง สำเนาจะยังคงอยู่บนอุปกรณ์ของสมาชิกแต่ละคนจนกว่าสมาชิกคนนั้นจะลบออก เมื่อสมาชิกออกจากพื้นที่หรือถูกนำออก สมาชิกคนนั้นจะสูญเสียสิทธิ์เข้าถึงข้อมูลบนเซิร์ฟเวอร์ของเรา หากการสมัครสมาชิกของคุณสิ้นสุดลง การซิงค์จะหยุดชั่วคราว และข้อมูลที่อัปโหลดไปแล้วจะยังคงอยู่บนเซิร์ฟเวอร์ของเราจนกว่าพื้นที่นั้นจะถูกลบ

บัญชีผู้ใช้

คุณลงชื่อเข้าใช้ด้วยการลงชื่อเข้าด้วย Apple หรือการลงชื่อเข้าด้วย Google เราได้รับโทเค็นยืนยันตัวตนจาก Apple หรือ Google และสร้างบัญชีกับผู้ให้บริการแบ็กเอนด์ของเรา คือ Supabase บัญชีนั้นอาจประกอบด้วย ID ผู้ใช้ ที่อยู่อีเมล (รวมถึงอีเมลส่งต่อจากฟีเจอร์ซ่อนอีเมลของฉันของ Apple) ชื่อของคุณ และรูปโปรไฟล์ของคุณในกรณีที่ใช้ Google คุณสามารถเปลี่ยนชื่อที่แสดงต่อสมาชิกคนอื่นได้ในแอป

คุณสามารถลบบัญชีของคุณได้ในแอป ซึ่งจะลบบัญชีและบันทึกการสมัครสมาชิกที่เราจัดเก็บไว้ หากคุณเป็นเจ้าของพื้นที่ที่แชร์ที่มีสมาชิกอื่น คุณต้องลบพื้นที่เหล่านั้นหรือนำสมาชิกออกก่อน ข้อมูลในพื้นที่ส่วนตัวบนอุปกรณ์เป็นส่วนที่แยกต่างหาก คุณยังสามารถล้างข้อมูลการเงินในเครื่องได้ในการตั้งค่า

การสมัครสมาชิกและการซื้อ

การซื้อดำเนินการโดย Apple เราใช้ RevenueCat เพื่ออ่านสถานะการสมัครสมาชิก เราจัดเก็บสถานะพรีเมียมและตัวนับการใช้งาน AI (จำนวนคำขอเสียง รูปภาพ และเอกสารที่คุณใช้ไปแล้ว) ไว้ใน Supabase โดยเชื่อมโยงกับ ID ผู้ใช้ของคุณ เราไม่ได้รับหรือจัดเก็บหมายเลขบัตรชำระเงิน

เสียง การสแกน เอกสาร และฟีเจอร์ AI อื่น ๆ

เมื่อคุณใช้การป้อนด้วยเสียง การสแกนใบเสร็จหรือเอกสาร หรือการดึงข้อมูลด้วย AI อื่น ๆ แอปจะส่งเนื้อหาที่คุณส่งไปยังแบ็กเอนด์ของเรา (Supabase Edge Functions) แบ็กเอนด์จะส่งต่อเนื้อหานั้นไปยัง OpenAI เพื่อให้แอปเสนอรายการได้

เนื้อหานั้นอาจรวมถึงสิ่งต่อไปนี้ ขึ้นอยู่กับฟีเจอร์:

  • เสียงพูด;
  • รูปถ่ายใบเสร็จ บิล รายการเดินบัญชี หรือเอกสารที่คล้ายกัน;
  • ข้อความที่ดึงมาจากเอกสาร;
  • ข้อความที่คุณพิมพ์;
  • ชื่อบัญชีและหมวดหมู่บนอุปกรณ์ พร้อมจำนวนเงินและสกุลเงินที่เกี่ยวข้อง เพื่อให้โมเดลจับคู่ได้

ข้อมูลนี้ถูกส่งเพื่อให้บริการฟีเจอร์ที่คุณร้องขอเท่านั้น เราไม่จัดเก็บเนื้อหาที่คุณส่งไว้ในฐานข้อมูลของเรา แบ็กเอนด์ใช้คำขอเพื่อส่งกลับรายการที่มีโครงสร้างและเพื่อนับการใช้งานตามขีดจำกัดของคุณ

OpenAI ประมวลผลคำขอภายใต้ข้อกำหนด API ของตน OpenAI ระบุว่าโดยค่าเริ่มต้น ข้อมูลที่ส่งผ่าน API จะไม่ถูกนำไปใช้ฝึกโมเดล OpenAI อาจเก็บรักษาข้อมูลไว้ในระยะเวลาจำกัดเพื่อดำเนินการ API และเพื่อตรวจสอบการใช้งานในทางที่ผิด ดูนโยบายของ OpenAI ตามลิงก์ด้านล่าง

ฟีเจอร์ AI เป็นตัวเลือก คุณสามารถเพิ่มรายการเองได้โดยไม่ต้องส่งเนื้อหานี้

การวิเคราะห์ การขัดข้อง และข้อมูลเครือข่ายอื่น ๆ

  • อัตราแลกเปลี่ยน แอปดาวน์โหลดข้อมูลอัตราแลกเปลี่ยนสกุลเงินสาธารณะจากเซิร์ฟเวอร์ของเรา ข้อมูลนี้ไม่ใช่บันทึกการเงินของคุณ
  • การวิเคราะห์ผลิตภัณฑ์ (PostHog) เราบันทึกเหตุการณ์ต่าง ๆ เช่น ฟีเจอร์ที่คุณใช้ จำนวนการใช้งานโดยประมาณ (เช่น จำนวนรายการ ไม่ใช่จำนวนเงิน) และภาษาของแอป เหตุการณ์จะเชื่อมโยงกับ ID ผู้ใช้ของคุณ เราไม่ส่งจำนวนเงินของรายการ โน้ต รูปภาพ หรือเสียงไปยัง PostHog
  • รายงานการขัดข้อง (Sentry) เราส่งข้อมูลวินิจฉัยการขัดข้องเพื่อช่วยแก้ไขข้อบกพร่อง เราไม่แนบภาพหน้าจอหรือข้อมูลส่วนบุคคลเพิ่มเติมไปกับรายงานเหล่านั้น
  • ข้อมูลทางเทคนิค เมื่อแอปติดต่อกับเซิร์ฟเวอร์หรือ SDK ฝ่ายนั้นมักได้รับข้อมูลทางเทคนิค เช่น ที่อยู่ IP ประเภทอุปกรณ์ และเวอร์ชันระบบปฏิบัติการ

สิ่งที่เราไม่ทำ

  • เราไม่ขายข้อมูลของคุณ
  • เราไม่ใช้ข้อมูลของคุณสำหรับเครือข่ายโฆษณา หรือเพื่อติดตามคุณในแอปและเว็บไซต์ของบริษัทอื่น
  • เราไม่เก็บตำแหน่ง GPS ที่แม่นยำ แอปใช้การตั้งค่าภาษาและภูมิภาคจากอุปกรณ์ ไม่ใช่ GPS

ผู้ประมวลผลข้อมูลบุคคลที่สาม

บริษัทเหล่านี้ประมวลผลข้อมูลตามที่อธิบายไว้ข้างต้น แต่ละบริษัทมีนโยบายความเป็นส่วนตัวของตนเอง:

  • Apple — การลงชื่อเข้าด้วย Apple, App Store, การซื้อภายในแอป, การสำรองข้อมูลไปยัง iCloud ซึ่งเป็นตัวเลือก
  • Google — การลงชื่อเข้าด้วย Google
  • Supabase — บัญชี บันทึกการสมัครสมาชิกและการใช้งาน พื้นที่ที่แชร์ ฟังก์ชันแบ็กเอนด์
  • OpenAI — การประมวลผลด้วย AI สำหรับเนื้อหาที่คุณส่ง (ความเป็นส่วนตัวของ API / องค์กร)
  • RevenueCat — สถานะการสมัครสมาชิก
  • PostHog — การวิเคราะห์ผลิตภัณฑ์
  • Sentry — รายงานการขัดข้อง
  • Expo — รันไทม์ของแอป

เราอาจเปิดเผยข้อมูลหากกฎหมายกำหนด หรือหากเราเชื่อโดยสุจริตว่าการเปิดเผยนั้นจำเป็นเพื่อปกป้องสิทธิ ความปลอดภัย หรือเพื่อสอบสวนการฉ้อโกง

การเก็บรักษาและการลบข้อมูล

  • ข้อมูลในพื้นที่ส่วนตัวจะอยู่บนอุปกรณ์ของคุณจนกว่าคุณจะลบหรือถอนการติดตั้งแอป (เว้นแต่คุณยังเก็บข้อมูลสำรองใน iCloud ไว้ด้วย)
  • ข้อมูลในพื้นที่ที่แชร์จะถูกเก็บไว้บนเซิร์ฟเวอร์ของเราตราบที่พื้นที่นั้นยังถูกแชร์อยู่ และจะถูกลบเมื่อเจ้าของหยุดแชร์หรือลบพื้นที่นั้น
  • บันทึกบัญชีและการใช้งานจะถูกเก็บไว้ตราบที่คุณมีบัญชี และจะถูกลบเมื่อคุณลบบัญชี โดยอาจใช้ระยะเวลาสั้น ๆ เพิ่มเติมที่จำเป็นเพื่อดำเนินการลบให้เสร็จสิ้น
  • ข้อมูลในคำขอ AI จะถูกประมวลผลเพื่อดำเนินการตามคำขอ เราไม่จัดเก็บข้อมูลเหล่านั้นเป็นบันทึกของคุณ ผู้ประมวลผลข้อมูลอาจเก็บรักษาไว้ตามนโยบายของตนเอง
  • ข้อมูลการวิเคราะห์และการขัดข้องจะถูกเก็บไว้เท่าที่จำเป็นเพื่อดำเนินการและปรับปรุงแอป

หากต้องการลบข้อมูลบัญชี ให้ใช้ฟีเจอร์ลบบัญชีในแอป หรือส่งอีเมลไปที่ help.qalta.app@outlook.com
