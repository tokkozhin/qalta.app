# MCP

AI アシスタントを Qalta のクラウドスペースに接続します。

## AI アシスタントを接続する

1.  Qalta にサインインし、使用するクラウドスペースが同期されていることを確認します。端末内だけに保存されたプライベートスペースはコネクターから利用できません。
2.  アシスタントの設定で MCP サーバー https://mcp.qalta.app/mcp を追加します。
3.  Qalta 経由でサインインし、アクセスを許可する前に権限を確認します。
4.  まずは「今月の食料品への支出はいくらですか？」のような読み取りリクエストを試してください。
