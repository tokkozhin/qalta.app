# Créer une dépense Qalta avec Toucher le dos

Utilisez Toucher le dos pour lancer un raccourci de dépense Qalta en touchant trois fois le dos de votre iPhone.

[Ajouter Back tap expense à Raccourcis](https://www.icloud.com/shortcuts/876c51a66dd1491ea01d86fa92e8247a)

## Configurer le triple toucher

1.  Ouvrez le lien ci-dessus sur votre iPhone et touchez **Ajouter le raccourci** dans Raccourcis. Il apparaîtra sous le nom **Back tap expense**.

2.  Ouvrez **Réglages → Accessibilité → Toucher → Toucher le dos**.

3.  Touchez **Triple toucher**, faites défiler jusqu’à **Raccourcis**, puis choisissez **Back tap expense**.

4.  Vous pouvez maintenant toucher trois fois le dos de votre iPhone. Le raccourci demande le montant et la catégorie, puis crée la dépense dans **Qalta**.

**Qalta est nécessaire.** À son lancement, le raccourci demande le montant et la catégorie de la dépense. Vérifiez que Qalta est installée.
