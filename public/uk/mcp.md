# MCP

Підключіть ШІ-асистента до хмарного простору Qalta.

## Підключити ШІ-асистента

1.  Увійдіть у Qalta та перевірте, чи синхронізується потрібний хмарний простір. Приватні простори, збережені лише на пристрої, недоступні для конектора.
2.  У налаштуваннях асистента додайте MCP-сервер https://mcp.qalta.app/mcp.
3.  Увійдіть через Qalta та перевірте дозволи, перш ніж підтверджувати доступ.
4.  Почніть із запиту лише на читання, наприклад: «Скільки я витратив на продукти цього місяця?»
