# MCP

Connect an AI assistant to your Qalta cloud space.

## Connect an AI assistant

1.  Sign in to Qalta and check that the cloud space you want to use is syncing. Private spaces stored only on your device are not available to the connector.
2.  In your assistant’s settings, add the MCP server https://mcp.qalta.app/mcp.
3.  Sign in through Qalta and review the permissions before approving access.
4.  Start with a read request, such as “How much did I spend on groceries this month?”
