# MCP

AI 어시스턴트를 Qalta 클라우드 공간에 연결하세요.

## AI 어시스턴트 연결

1.  Qalta에 로그인하고 사용할 클라우드 공간이 동기화 중인지 확인하세요. 기기에만 저장된 비공개 공간은 커넥터에서 사용할 수 없습니다.
2.  어시스턴트 설정에서 MCP 서버 https://mcp.qalta.app/mcp 를 추가하세요.
3.  Qalta를 통해 로그인하고 액세스를 승인하기 전에 권한을 확인하세요.
4.  먼저 “이번 달 식료품에 얼마를 썼나요?”와 같은 읽기 요청으로 시작하세요.
