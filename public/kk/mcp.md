# MCP

ЖИ көмекшісін Qalta бұлт кеңістігіне қосыңыз.

## ЖИ көмекшісін қосу

1.  Qalta жүйесіне кіріп, пайдаланғыңыз келетін бұлт кеңістігінің синхрондалып тұрғанын тексеріңіз. Тек құрылғыда сақталған жеке кеңістіктер коннекторға қолжетімді емес.
2.  Көмекшінің баптауларында MCP серверін қосыңыз: https://mcp.qalta.app/mcp.
3.  Qalta арқылы кіріп, қолжетімділікті растаудан бұрын рұқсаттарды тексеріңіз.
4.  Алдымен «Осы айда азық-түлікке қанша жұмсадым?» сияқты тек оқитын сұраудан бастаңыз.
